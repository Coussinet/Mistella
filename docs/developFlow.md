# AIを活用したアプリ開発手順書 (YoruConnect)

この手順書は、生成AIと対話しながら「YoruConnect」のコードを生成し、アプリを完成・公開させるためのステップバイステップのガイドです。

## Phase 1: プロジェクトの初期化 (あなたが行う作業)

1. **Expoプロジェクトの作成:** ターミナルで以下を実行します。
    
    ```
    npx create-expo-app YoruConnect -t expo-template-blank-typescript
    cd YoruConnect
    ```
    
2. **Supabaseプロジェクトの作成:** Supabase公式サイトでプロジェクトを作成します。**※「Free Plan」を選択してください。**

## Phase 2: データベースとバックエンドの構築 (AIに指示)

1. AIに対して、「**データベース定義書 (db_schema.md)**」を貼り付けます。
2. **プロンプト例:**
    
    > 「データベース定義書に基づいて、SupabaseのSQLエディタで実行するためのテーブル作成SQLを作成してください。また、情報漏洩を防ぐため、顧客からキャストのメモ(`customer_notes`)が絶対に見えないような強力なRLS設定も含めてください。」
    > 
3. 出力されたSQLをSupabaseで実行します。

## Phase 3: フロントエンド基盤構築 ＆ クライアント最適化 (AIに指示)

1. AIに対して、「**技術仕様書 (tech_specs.md)**」を貼り付けます。
2. **プロンプト例:**
    
    > 「技術仕様書に基づいて必要なパッケージをインストールするコマンドを出力してください。その後、Supabase無料枠のストレージを節約するため、画像をアップロードする前に `expo-image-manipulator` で圧縮・リサイズするユーティリティ関数を作成してください。」
    > 

## Phase 4: 認証機能の実装 (AIに指示)

1. **プロンプト例:**
    
    > 「Supabase Authを使用したログイン・登録画面を作成してください。日本向けの洗練されたダークテーマに合うデザイン（ネイティブのUIに近い角丸、落ち着いた色合い）にしてください。登録時はキャストか顧客かを選択させます。」
    > 

## Phase 5: コア機能の実装 (機能ごとに細かくAIに指示)

以下の機能を、**一つずつ**プロンプトで依頼して作成していきます。

- **タイムライン:** 「画像圧縮を適用したタイムライン投稿機能と、無限スクロールによる一覧表示機能を作成してください。」
- **検索・広告枠表示:** 「顧客向けにキャスト検索画面を作成してください。`cast_profiles` の `is_sponsored` が true のユーザーを一覧の上部にハイライト表示（金の枠線やSponsoredバッジ）するデザインを適用してください。」
- **今夜行ける？機能:** 「顧客がキャストのプロフィール画面から『今夜行ける？』ボタンをタップし、`tonight_requests` テーブルにデータを挿入する処理を作成してください。」
- **自動来店リマインダー:** 「キャスト向けのCRM画面で、`next_visit_date` が近い顧客をリストの上部に強調表示（またはアプリ内通知として表示）する機能を作成してください。」

## Phase 6: 無料枠対策のバッチ処理実装 (AIに指示)

1. **プロンプト例:**
    
    > 「Supabase無料枠のデータベース容量を節約するため、24時間経過した `timelines` のレコードを物理削除する `pg_cron` の設定SQLを書いてください。」
    > 

## Phase 7: デバッグと公開準備

1. エラーはAIにそのまま貼り付けて解決します。
2. EAS Buildを使用してアプリをビルドし、iOS/Androidそれぞれのストアに申請します（申請時のプライバシーポリシー作成などもAIに依頼できます）。
