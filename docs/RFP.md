# 要件定義書：夜職向けマッチングSNSアプリ「YoruConnect」

本ドキュメントは、生成AIを用いたアプリ開発における基盤となる要件定義書です。AIに後続の設計書やコードを生成させる際の「システムプロンプト（前提知識）」として機能するように構造化されています。

## 1. プロジェクト概要

- **アプリ名称:** YoruConnect (ヨルコネ)
- **コンセプト:** ガールズバーやコンカフェの女性キャストと男性顧客が、アプリ上でタイムラインやマッチングを通じて知り合い、個別メッセージが可能な夜職向け特化型SNS。
- **ターゲットユーザー:**
    - **キャスト（女性）:** 10代後半〜20代。集客を増やしたい、顧客管理を効率化したい層。
    - **顧客（男性）:** 30代〜50代。お気に入りのキャストを見つけたい、出勤情報を知りたい、お店に行く前に仲良くなりたい層。

## 2. システム要件・マネタイズ戦略

### 2.1 インフラ・技術スタック

- **フロントエンド:** React Native (Expo)
    - iOS/Android両対応。AIによるコード生成精度が最も高い構成を採用。
- **バックエンド:** Supabase
    - 開発初期は「Supabaseの無料枠（Free Plan）の範囲内」で運用できる設計と実装を行う（データベース容量、Storage容量、同時接続数などを考慮した最適化）。

### 2.2 マネタイズ戦略

1. **店舗向けの広告・掲載枠販売 (BtoB収益) 【初期実装】**
    - アプリの主要な収益源。キャスト検索画面やマップ画面において、広告枠を購入した店舗のキャストを優先表示（上位表示やリッチなUIでのハイライト）する仕組みを実装する。
2. **男性向けプレミアムプラン (BtoC収益) 【将来実装】**
    - 月額課金（サブスクリプション）。メッセージの既読確認、足跡の無制限閲覧、シークレットモード等の機能を提供する。
    - **※公開当初は無料提供とするが、データベース設計やシステム構造はプレミアムプランの導入を前提とした拡張性を持たせておく。**

## 3. 機能要件 (Must機能)

システムは「顧客（男性）」「キャスト（女性）」の権限によって提供するUI/UXを完全に分離する。

### 3.1 共通機能

- **認証・アカウント管理:** ユーザー登録、ログイン、パスワードリセット。登録時に「男性(顧客)」か「女性(キャスト)」を選択。
- **プロフィール（マイページ）設定:** アイコン、自己紹介文の設定。
- **タイムライン（ストーリーズ）閲覧・投稿:**
    - テキスト、写真、最大3秒の動画投稿。
    - 投稿は24時間経過後、データベースのストレージ節約（Supabase無料枠対策）のため、自動削除（CRON処理または期限切れデータの論理削除・定期物理削除）を行う。
- **ユーザー一覧・検索・マッチング:**
    - スワイプ、または一覧リスト形式での「いいね」機能。
    - 相互「いいね」でマッチング成立。
- **ダイレクトメッセージ (DM):** マッチング成立後の1対1のテキストチャット。画像送信可。
- **お気に入り・足跡機能:** 気になるユーザーの保存、自分のプロフィールを見た人の履歴表示。

### 3.2 キャスト（女性）専用機能

- **出勤・オンラインステータス変更:** 「出勤中（オンライン）」「休憩中」「退勤」などのステータスをワンタップで切り替え。
- **位置情報の共有（ON/OFF）:** 出勤中のみ、現在地情報を元に顧客アプリの「近くのキャスト」として表示させる（プライバシー保護のため、「〇〇エリア周辺」等のぼかし処理を行う）。
- **所属店舗情報管理:** 所属店舗名、住所、料金システムなどの登録・編集。
- **「今夜行ける？」機能の受信:** 顧客からの「今夜お店に行ける」アピールを受け取り、一覧で確認・返信できる機能。
- **顧客管理機能 (CRM - Private Note) & 自動来店リマインダー:**
    - 顧客ごとに自分だけが見られるメモを残す機能（呼ばれた名前、会話内容、ボトル履歴、誕生日、趣味など）。
    - **自動来店リマインダー:** メモに「次回来店予定日」や「誕生日」を登録すると、該当日の数日前にアプリ内で自動的にリマインド通知（プッシュ通知またはアプリ内アラート）を行う。

### 3.3 顧客（男性）専用機能

- **キャスト検索:** エリア、出勤ステータス、店舗名、キーワードなどでの絞り込み。※広告枠購入店舗のキャストを上位・リッチ表示する。
- **マップ・近隣キャスト表示:** 「出勤中」かつ位置情報ONのキャストを現在地周辺から探す機能。
- **「今夜行ける？」機能（アピール送信）:** 「今夜お店行けるよ」という意思表示を、お気に入りや特定のキャスト、または現在地周辺のキャストに対してワンタップでアピール（通知）する機能。

## 4. 非機能要件・デザイン (UI/UX)

- **プラットフォーム:** iOS / Android
- **デザイン・UI/UX方針 (日本市場向け最新トレンド):**
    - ナイトワーク特有の「ギラギラ感」を抑え、クリーンで洗練された「モダン・ダークテーマ」を基調とする（日本人が好む透明感や余白を活かしたUI）。
    - 情報を詰め込まず、主要なアクション（いいね、メッセージ、今夜行けるボタン）が直感的にわかるように、ボトムシートやフローティングアクションボタン（FAB）を効果的に活用する。
    - アニメーションは過度にならず、画面遷移や「いいね」時のマイクロインタラクションを滑らかに行い、高級感を演出する。
- **セキュリティ:** 個人情報の暗号化、スパム・悪質ユーザーのブロック・通報機能。
